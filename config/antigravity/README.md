# Antigravity Workspace Configuration

> **Master Plan Reference**: Section 4 (AI Tool Responsibility Matrix)

## Purpose

Configuration for the Antigravity AI development environment, used for Google Pay MCP integration and codelab implementation.

## Setup

Antigravity workspace settings are configured within the Antigravity tool itself. This directory stores reference documentation and any exportable configuration.

## Usage

1. Open the project in Antigravity
2. Connect to the Google Pay MCP Server (see config/mcp/)
3. Use spec-driven development workflow for feature implementation
4. Log all interactions in docs/ai-log/
